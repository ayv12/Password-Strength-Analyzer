# 🔐 Password-Strength-Analyzer
A cybersecurity-focused Flask web application that evaluates password strength using multiple security parameters like length, uppercase, numbers, and special characters, helping users build stronger credentials.


---

## 🚀 Live Demo
https://password-strength-analyzer-15av.onrender.com

---

## 🛠️ Tech Stack
- Python (Flask)
- HTML
- CSS
- Jinja2 Templates

---

## ⚡ Features
- Password strength checker (Weak / Medium / Strong)
- Validates password security requirements
- Simple and responsive UI
- Real-time feedback using Flask backend
